# Contact Management System

A single-file HTML contact management application.

## Features
- Add, edit, and delete contacts
- Search by name, phone, email, category, or notes
- Contacts remain saved in the same browser using localStorage
- Responsive design for desktop and mobile

## Run it
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html` and select **Open with Live Server**.

You can also double-click `index.html` to open it in a browser.

## Note
Contact data is stored only in your browser. Clearing browser site data or local storage will remove it.
